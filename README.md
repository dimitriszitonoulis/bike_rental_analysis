# bike_rental_analysis

Time series analysis for bike rentals.

## Install libraries

Create a `venv`:

```bash
python -m venv /path/to/venv
```

Activate the `venv`

- On windows:

```cmd
\path\to\venv\Scripts\activate
```

- On linux:

```bash
source /path/to/venv/bin/activate
```

Use the following command to install the needed libraries:

```bash
pip install -r /path/to/requirements.txt
```
